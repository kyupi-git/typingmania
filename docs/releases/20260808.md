# TypingManiaNovel 20260808

TypingManiaNovel 20260808 keeps TypingMania NEO-compatible scoring and adds
player-facing improvements for play, imports, metadata, and Windows startup.

## Highlights

- Choose Standard, Simple, or Demo; Standard is the default. Simple asks for
  the initial of each Chinese character, Japanese reading unit, or English
  word, then completes the rest automatically; assisted input is separate from
  CPM and ordinary scores.
- Use Network & source status to review regional routes, proxy mode, latency,
  device region, proxy-exit region, and recent reachability. A background
  preflight checks official endpoints and trusted mirrors, improving later
  imports without delaying normal play.
- Manage reading, lyrics, identity, direct production, cover, and poster status
  together in Song info & editing, with sorting, duplicate review, refresh, and
  safe cleanup.
- Imports and refreshes now cross-check exact recording identity, complete vocal
  lyrics, direct-production type and original title, and artwork across
  suitable independent sources. Japanese ruby and recording-specific timed
  readings are preferred; offline dictionary readings remain playable as
  `pending`. A trustworthy provider or embedded artist label may remain
  pending when online proof is unavailable; biographies, copyright notices,
  unknown or malformed fields stay blank.
- Identity protection keeps a verified song or artist from being overwritten by
  a near-match or cover. Character voice credits use `Character (CV: voice actor)`
  only with direct evidence; biographies and copyright text are not singers or
  lyrics.
- Demo advances line by line only after accepted input, remaining stable at high
  CPM and low frame rates.

## Install

Download `TypingManiaNovel-20260808-Windows-x64.zip`, extract it, and
double-click `start-game.cmd`. The launcher uses PowerShell 7 when available
and automatically falls back to the Windows 11 built-in Windows PowerShell when
it is not. Node.js, npm, Python, FFmpeg, and importer setup are included; no
separate installation is required.

The public archive contains only the three generated starter songs. Imported
audio, lyrics, artwork, MVs, account/session data, music-client caches, proxy
settings, logs, and private library state stay local and are not included.

See [CHANGELOG.md](../../CHANGELOG.md) for the changes since `20260726` and
[the import guide](../importing-music.md) for shared validation rules.
