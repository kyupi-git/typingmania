# Starter songs

`scripts/build-offline-demo.js` generates three self-contained starter
packages:

1. `demo-chinese.typingmania` — Chinese lyrics and tone-free pinyin
2. `demo-english.typingmania` — English lyrics
3. `demo-japanese.typingmania` — Japanese lyrics and romaji

Their fixed added-time metadata keeps that order when the library uses its
default ascending added-time sort. The melody, lyrics, metadata, and SVG
artwork were created for TypingManiaNovel and are distributed under the
repository's Apache-2.0 license.

The starter songs contain no QQ Music or account data and make no network
request.
